# java-racingcar-precourse
기능 단위로 나눠서 커밋할 수 있도록 작성

사용자 입력 기능

자동차 이름 입력 받기

이동 횟수 입력 받기

잘못된 값 입력 시 IllegalArgumentException 발생

자동차 초기화

입력받은 자동차 이름으로 Car 객체 생성

자동차 이름 5자 제한 적용

랜덤 이동 로직

0~9 사이 무작위 값 생성 (Randoms.pickNumberInRange(0, 9))

값이 4 이상이면 전진, 아니면 정지

자동차마다 이동 기록 저장

경주 실행

입력받은 시도 횟수만큼 이동 시뮬레이션

각 시도별 자동차 전진 상태 출력

우승자 결정

최대 이동 거리 계산

최대 거리 자동차 이름 모두 출력 (공동 우승 가능)

최종 우승자 안내 문구 출력

출력 기능

자동차별 진행 상황 출력

최종 우승자 출력
